# hf_type_mortality experiment

Run `python disease_progression/scripts/hf_type_mortality/reproduce_experiments.py` from the repository root with pandas, scikit-learn, SciPy, lifelines, PyArrow and Matplotlib installed. `config.json` specifies the dataset, output paths, time horizons and model parameters. Run `prepare_cohort.py` by itself to regenerate the filtered Parquet, its attribute schema and the vector cohort flowchart.

Eligibility starts at the index date and requires the first registration anniversary to have occurred, a populated field among the schema's pre- or post-index hospitalization columns, and a recorded HF type. Populated zero counts qualify. Post-index fields contribute to the requested eligibility rule, which can select on availability of follow-up data and limits interpretation as an index-date deployment cohort.

The Random Forest uses the schema's baseline predictors. Within each horizon, death on or before the horizon is positive and observed survival to the horizon is negative. Earlier censoring makes the outcome unknown. Five shuffled folds preserve the joint distribution of the binary outcome and follow-up bands from `days_to_event`. The existing median/mode imputation pipeline is fitted within each fold. The pooled metrics use held-out predictions and describe patients with known outcome at that horizon. Feature importance uses a full-data fit for each horizon and reports total impurity-based importance by source feature. Each horizon also includes numeric quartiles and categorical distributions by observed class.

The Cox model uses all observed follow-up after cohort selection, with sex, HF type, their interaction and linear age. Joint-group indicators implement the interaction, allowing comparisons within each sex and within each HF type. Pairwise hazard ratios use pointwise Wald 95% confidence intervals. The 1-, 2- and 5-year absolute risks are model-based predictions averaged over the same pooled age distribution for each group. Review the proportional hazards tests before interpreting the hazard ratios as constant over follow-up.

The sensitivity model stratifies by completed year of age and compares HF type and sex within those strata. This allows age-specific baseline hazards and removes the need for a time-constant linear age effect. Its pairwise hazard ratios are written to `cox_age_stratified_pairwise_hazard_ratios.csv`.
